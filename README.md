# Frames

A desktop image viewer. Each folder is a row, and each image in that folder is a title in the row.

## Download

Install the latest Windows release from the [releases page](https://github.com/RocamboleLindus/frames/releases/latest).

After installation, launch Frames from the desktop shortcut. **Add folder** puts a folder on its own row. Frames reads the images directly inside that folder. **Update** checks this repository and installs a newer release.
